# v0 Agent Instructions

## Project Overview

- **Type**: Next.js 16 Web Application (App Router)
- **Purpose**: Multi-dashboard civic monitoring system for Calbayog City — weather, fire, flood, crime, medical, infrastructure data
- **Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Radix UI, Recharts, @dnd-kit, SST (serverless)

## Design System

- **Styling**: Tailwind CSS v4 with OKLCH CSS variables (`app/globals.css`)
- **Components**: Radix UI primitives + custom components
- **Icons**: Lucide React
- **Charts**: Recharts (line, bar, area, radar, composed) + custom SVG (gauge, compass, wind rose, heatmaps)
- **Theme**: 8 themes × 3 modes (dark/soft/light) via `next-themes` and `[data-theme]` CSS selectors
- **Grid**: CSS Grid with @dnd-kit drag-and-drop reordering

### Theme Tokens (use these CSS variables)

- `--background`, `--foreground`, `--card`, `--card-foreground`
- `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive`
- `--border`, `--ring`, `--sidebar-*` variants
- `--chart-1` through `--chart-5` for Recharts colors

### Chart Component Patterns

Each chart component follows this structure:
- Wrapped in a `<Card>` with `<CardHeader>` and `<CardContent>`
- Uses `ResponsiveContainer` from Recharts (width="100%" height={…})
- Colors reference CSS variables: `hsl(var(--chart-1))`
- Custom SVG charts use inline `<svg>` with viewBox

Existing chart types: LineChart, BarChart, AreaChart, ScatterChart, ComposedChart, BulletChart, SparkBar, RadarChart, GaugeArc, WindRose, Compass, SunriseSunset, MoonPhase, TimelineHeatmap, CalendarHeatmap, StatCard, LocalForecast, RadialChart, TempHumidityBar, MultiTempBar, RainBar

## Dashboard Layout

Each dashboard route loads a **preset** from `lib/presets.ts` defining a grid of `ChartBlock` items. The `DashboardGrid` component renders these as a CSS Grid with drag handles.

Block structure: `{ id, type, title, dataKey, span?, description? }`

## Guidelines

1. Use existing component patterns from `components/charts/` — match Card + Recharts structure
2. All colors must use CSS variables, never hardcoded values
3. Follow Radix UI patterns for interactive elements (Dialog, Sheet, Popover, etc.)
4. Icons: Lucide React only
5. Markup is v0's domain — logic and data wiring are handled by opencode/Claude
6. New charts should export a default component matching the existing naming convention
